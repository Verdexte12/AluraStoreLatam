# AluraStoreLatam

El proposito de este codigo es ayudar al Sr.Juan a decidir que tienda vender para poder empezar su nuevo emprendimiento

Primero determine cuanto generaba cada tienda, luego calcule la cantidad de ventas x categoria, luego la calificacion de cada una de las tiendas, los productos mas y menos vendidos de cada una y por ultimo los costes de envio promedio de cada una
